# Partido Missão — História e Propostas

Site informativo desenvolvido como **atividade acadêmica**, com o objetivo de apresentar a história do Movimento Brasil Livre (MBL), o processo de criação do Partido Missão e suas propostas políticas no contexto das eleições presidenciais de 2026.

> **Aviso:** este é um projeto educacional e independente. Não é um site oficial do MBL ou do Partido Missão e não representa apoio ou vínculo institucional com essas organizações.

## 📖 Conteúdo do site

O projeto está dividido em seis páginas:

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Apresentação e navegação inicial |
| `pagina1.html` | História e criação do MBL |
| `pagina2.html` | Surgimento e registro do Partido Missão |
| `pagina3.html` | Propostas políticas do partido |
| `pagina4.html` | Participação nas eleições presidenciais de 2026 |
| `pagina5.html` | Fontes e referências utilizadas |

## 🎨 Funcionalidades

- Navegação entre as páginas por meio de um menu lateral.
- Identidade visual inspirada nas cores **amarelo, preto e branco**.
- Layout responsivo, adaptado a celulares e computadores.
- Imagens, legendas e links para fontes de pesquisa.
- **CSS integrado a cada arquivo HTML**, sem folhas de estilo externas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** layout, cores, tipografia e responsividade.

O site é estático e não precisa de dependências, bibliotecas ou frameworks para funcionar.

## 💻 Como executar localmente

1. Clone o repositório ou baixe seus arquivos em ZIP.
2. Abra a pasta no **Visual Studio Code**.
3. Abra `index.html` no navegador ou use a extensão **Live Server**.

> Algumas imagens são carregadas de endereços externos e podem depender de conexão com a internet e da disponibilidade do site de origem.

## 🚀 Publicação na Vercel

1. Envie os arquivos para um repositório no GitHub.
2. Acesse [vercel.com/new](https://vercel.com/new).
3. Importe o repositório.
4. Em **Framework Preset**, escolha **Other** (se solicitado).
5. Mantenha a raiz do projeto como diretório de publicação e clique em **Deploy**.

Como o projeto utiliza apenas HTML e CSS, **não é necessário configurar um comando de build**.
